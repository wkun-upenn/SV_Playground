This directory is not part of the lab exercises, it it to test that JasperGold is installed and licensed.
To run the test :       $> ./testscript.sh

If the software and licences are OK then you will see the JasperGold GUI.
There will be a property table with some Asserts and Covers with a green tick next to them and some Asserts and Covers with a red cross next to them.
If you see what was just described then everything is OK.
